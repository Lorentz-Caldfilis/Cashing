# Cashing 当前版本

当前版本为 **1.2.0 Windows x64 预发行版**，源码与 Windows 版本资源保持一致。
支持快速录入、可选用途、本地分类学习、草稿、编辑撤销、月统计、搜索、本地备份及跟随系统浅色/深色。
没有图片背景功能。匹配准确性与 UI/操作优化仍为持续开发项。
