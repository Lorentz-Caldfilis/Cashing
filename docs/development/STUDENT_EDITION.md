## 批次 1：输入安全

原因：直接覆盖草稿可能截断旧文件；仅退出时保存无法应对进程意外结束；撤销覆盖下一笔输入。
改为同目录临时文件 + flush/fsync + 原子替换，350ms 防抖保存，账单写入后立即清除草稿。
保存失败保留旧文件并提示；关闭时失败保留窗口。撤销在输入非空或手动选择时间时保留新输入。
这是 best-effort 草稿恢复，不宣称抵抗全部断电场景；账单提交和 JSON 草稿不是跨文件事务。
回退：revert 本批提交；schema 不变，旧客户端可读账本和草稿。

## 批次 2：可逆学习与备份

分类编辑增加“自动判断”：删除本条个人标签，保留事实，按剩余标签重新派生类别。
允许明确选择已经显示的类别；仅打开编辑不会制造训练样本。编辑反馈提供撤销，
恢复原始类别来源及时间戳；事务内检查当前记录，拒绝覆盖后续修改。
类别提示说明是自己指定还是本机判断，不声称算法置信度或真实使用精度。

更多菜单增加 SQLite 一致快照备份：运行中可用、完整性检查、同目录临时文件完成后
以不覆盖的硬链接发布。目标已存在或文件系统不支持硬链接时失败并保留原文件。
拒绝给缺失 records 表的版本化数据库/其他应用数据库悄悄创建空账本。
测试：分类/Review/Ledger 35 项通过，备份及损坏结构保护 5 项通过。
回退：revert 本批提交；无 schema 变更。独立备份仍是标准 schema v3 SQLite。
