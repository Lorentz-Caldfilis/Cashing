# Cashing 使用指南

Cashing 是面向个人的 Windows 本地消费记录工具：记一笔，再看这个月。
没有账号、遥测、云同步或联网分类。当前 Student edition 是开发候选，尚未正式发布。

## 安装和第一次记账

从维护者提供的可信候选 ZIP 完整解压，进入 Cashing 文件夹，双击 Cashing.exe。
不要在 ZIP 预览里运行；保留整个文件夹，尤其是 _internal，无需另装 Python。
候选程序尚未数字签名。若系统阻止启动，先核对来源与提供的 SHA-256，不要关闭系统安全功能。

在“记一笔”输入 `18.5`，按 Enter，输入 `午饭`，再按 Enter。
只有写入成功才清空输入；底部通知可以撤销。输入错误时原内容保留，修改后重试。
金额为空时也可粘贴 `18.5 午饭`，检查金额与说明后按 Enter 保存；粘贴不会直接记账。
未写完的输入会在短暂停顿后保存为草稿，下次启动恢复，草稿不计入月总额。
时间下方“用途”可直接选择生活、工具、娱乐，再次点击所选项取消。留空自动判断；主动选择以“自选”保存，并用于本机分类学习。选择会随草稿恢复，保存成功后清空，失败保留。

界面自动跟随系统的浅色/深色设置，运行中切换系统颜色也会更新，无需重启。两页、输入与选区、菜单、时间选择和提示使用对应颜色；切换不清空草稿或结束正在编辑的记录。没有单独的主题开关或图片背景入口。

## 看账单、纠错和学习

点击底部“看账单”。月份两侧箭头切换月份，放大镜搜索历史说明。
点击记录即可修改金额、说明、时间或类别；Enter 完成，Esc 取消尚未提交的字段。
离开字段可能已提交修改，已提交的修改请用底部通知“撤销”。非法输入需要改正或取消才能离开。

“自动”表示本机判断，“自选”表示你明确选过；“暂未判断”不影响金额和总额，也不要求处理。
类别只有生活、工具、娱乐。点击类别可纠正；你的选择只在这台设备的账本中学习。
选择“自动判断”会移除这条记录的个人标签；最近一次纠正可撤销，撤销也恢复学习来源。
含平台名或含义不明确的说明可能保持未判断，这是保守处理，不代表记录丢失。
同一句话可以用于不同用途；学习是有限的短语规则，不保证理解所有消费。

进入编辑后可点右侧删除或选中记录按 Delete；删除也通过底部通知撤销。
Ctrl+Alt+Z 撤销当前通知的操作，Ctrl+Z 仍用于文本编辑。撤销不跨重启保存。
Alt+← / Alt+→ 切换两个空间，Tab / Shift+Tab 移动焦点。

## 数据在哪里

“⋮ → 打开数据目录”打开实际目录，“关于 Cashing”显示数据库路径。
Windows 默认是 `%LOCALAPPDATA%\Cashing`：

- `ledger.sqlite3`：账单和个人分类标签。
- `draft.json`：未完成输入。
- `cashing.log` 及轮转日志：错误诊断；分享前检查是否含个人路径或内容。

这些文件未加密，应按个人账本保管。程序目录与数据目录分离，替换程序不会删除账单。
旧账本升级前会生成 `.before-v3.bak`；这不是定时备份。结构损坏或未知格式会报错，不自动清空。

## 备份与恢复

1. 在“⋮ → 备份账本…”选择一个新文件名，建议存到本地 NTFS 磁盘。
2. 等待成功提示。备份包含账单和个人分类标签，不含草稿或日志；不会覆盖已有文件。
3. 定期将备份复制到自己信任的另一存储设备。软件没有云备份或定时备份。

恢复时：先在菜单中打开数据目录，然后关闭所有 Cashing 窗口。
保留当前整个数据目录的副本，再将它重命名另存，创建一个新的 Cashing 数据目录，
把选定的备份复制进去并命名为 `ledger.sqlite3`。这样不会混用旧数据库的 journal/WAL 文件或草稿。
重新启动，核对月份总额和几条记录。若报错，保留备份和原目录，不要反复覆盖或删除。
使用自定义 `--data-dir` 时，对“关于”显示的实际目录执行相同步骤。
备份功能若提示磁盘不支持，请换本地目录；失败不会改动原账本。

## 更新与卸载

更新前先备份、关闭所有窗口，将新版解压到新的程序目录，核对账单后再移除旧程序目录。
1.2.0 更新已移除图片背景。早期试用版遗留的 `appearance-background.png` 不再读取或改写，也不会自动删除；可自行另存或删除该图片，不影响账本。
不要用旧版 v1.0.0 打开已升级为 schema v3 的账本。

卸载只需关闭程序并删除解压的程序目录及自己创建的快捷方式；账本仍保留。
若也要删除账本，先确认备份，再手动删除“打开数据目录”显示的目录。删除账本不可通过软件撤销。

## 范围与问题反馈

当前仅记录人民币消费，没有收入、预算、账户、云同步或报表导出。
遇到问题时记录版本、操作步骤、错误摘要；请用合成例子，不上传个人账本、备份或完整日志。
Windows Actions 的自动检查不能替代真实中文输入法、触控板、多显示器和物理断网验收。

### 较多记录与版本回退

月份或搜索超过 60 条时，列表底部显示“当前范围 / 总条数”和上一页、下一页。
分页只限制当前绘制的记录，月份总额仍包含整月；搜索也会检查全部历史。
非法输入会阻止翻页，先修正或按 Esc 取消。

若需要回到升级前的旧程序，请先保留当前整个数据目录，另建目录并把
`ledger.sqlite3.before-v3.bak` 复制为 `ledger.sqlite3`，再用对应旧版打开这份副本。
该副本仅包含升级前记录；升级后新增或修改不会自动回到旧版。不要让旧程序打开 v3 文件，
也不要通过手改 schema 版本号降级。当前候选之间的代码回退不需要降级 v3 数据。
