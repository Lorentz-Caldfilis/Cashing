# 开源候选准备清单

2026-09-30。本项目仍未授予公开开源许可证；此文不改变许可，也不授权公开仓库或发布。
本分支是可审查的开发候选，不是已完成 Windows 发布验收的发行版。

## 已具备

- 本地 SQLite、无账号、无遥测、无运行时网络服务；金额整数分，自动分类不写回训练数据。
- 清晰的数据 / 业务 / Qt UI 分层；Qt 无关的粘贴解析与分类测试。
- v1/v2 到 v3 的验证、备份、事务迁移；未知或损坏库拒绝重建。
- 原子草稿、失败时保留输入、编辑/分类撤销、拒绝覆盖文件的手动备份。
- 合成数据单元/GUI 测试、可复现 GUI 进程验收与截图脚本。
- 维护说明、设计变更理由、回退步骤、运行及验收矩阵。
- `.gitignore` 排除真实账本、日志、缓存、凭据和生成包；本轮不提交合成数据库。

## 已知边界

备份未加密、非自动轮转；备份目标文件系统需要支持硬链接（例如 NTFS），失败时换本地目录。
草稿与账单是两个文件，不提供跨文件事务；极端断电仍可能恢复刚记录过的草稿，重启后需核对。
撤销仅在最近通知有效期间可用，不能跨重启恢复删除。没有收入、账户、预算、导入或导出报表。
分类合成基准不代表真实学生长期使用效果。第二阶段的平台词中性化已在 `7fda6b5` 撤回，
因为弱子串会导致错误决定；当前覆盖与错误决定分开报告，见 [第三阶段记录](development/STUDENT_PHASE3.md)。
