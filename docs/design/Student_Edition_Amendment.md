# PC Student edition 设计修订（2026-09-30）

> 后续审查发现平台词中性化会放大弱子串误判，该词表调整已保守撤回；见 [第三阶段修复](../development/STUDENT_PHASE3.md)。第二阶段数字保留为历史结果，不代表当前分类表现。

本轮用户授权重新审视除本地优先和习惯学习之外的设计哲学。以下限定条款优先于旧规范；
其他条款继续适用。不是全面改写产品定位，也不改变许可证或发布状态。

| 原规则 | 新行为与原因 |
|---|---|
| 无文字圆点、隐藏式边缘切换 | 两个原生按钮“记一笔 / 看账单”，维持底部与固定左右关系；新用户无需猜测圆点用途，键盘能直接到达。边缘、Alt+方向键仍可用。 |
| 品牌在使用页面完全退场 | 左上角小号 Cashing 标识帮助识别窗口，金额仍是主视觉；不加品牌动画。 |
| Capture 只有输入内容 | 增加“记下这一笔”、回车路径和粘贴提示；首次使用不需要读说明书。无新增必填字段。 |
| 仅标准数字逐字段输入 | 空金额框 Ctrl+V 可粘贴人民币金额及说明（如 `18.5 午饭`）；完整校验，只填入待确认内容，不自动保存。多行、外币、非法精度和可能截断的说明整体拒绝。 |
| 撤销保存必定恢复原输入 | 如果下一笔已输入或时间已手动选择，保留下一笔；账本仍撤销上一笔。优先避免覆盖尚未保存的劳动。 |
| 编辑只能继续纠正 | 每次已提交字段修改提供短时撤销，恢复原始类别来源与学习标签；拒绝覆盖后续修改。原生 Ctrl+Z 继续属于文本；Ctrl+Alt+Z 撤销通知中的操作。 |
| 用户指定类别只能再指定 | “自动判断”移除当前记录的个人标签；其余历史纠正继续参与学习。明确选中相同类别也能确认个人选择，未交互不产生标签。 |
| 草稿关闭时保存 | 输入停止 350ms 后原子替换，提交/撤销后立即同步；退出时写失败保留窗口和输入。仍不保证跨账本与草稿文件的断电事务。 |
| Utility 只有目录和关于 | 添加本地账本备份，降低手动复制出错风险；没有第三个空间、登录、遥测或网络依赖。 |

类别仍是生活、工具、娱乐或暂未判断；金额仍存整数分。算法不读取真实个人数据作开发评估，
不把自动类别写回当训练样本。三个类别的算法参数与词库本轮未调整。

视觉继续沿用浅色、集中内容列、克制动效。次级阅读色加深，主按钮改为更清晰的蓝色。
说明输入固定可用宽度，避免提示和输入过早被省略；长通知限制宽度并换行。

回退：按开发记录反向 revert 各批提交；schema 保持 v3，不需要逆迁移。

## 第二阶段补充（同日）

- 分类行显示“自动 / 自选”和“暂未判断”，使来源与纠错入口不依赖悬停；仍不是待办或第四类别。
  未指定类别的编辑框显示“自动判断”，只有实际分类控件交互才生成个人标签。
- 空账单提供“记一笔”直接入口，不增加首次启动向导。
- Tab / Shift+Tab 只遍历当前空间及窗口公共控件，滑出屏幕的空间不接收焦点。
- 680×440 等短窗口允许录入区滚动；错误详情有独立可滚动、可复制区域，错误出现后自动可见。
  短窗口隐藏非必要标题与键盘提示，保留输入、时间和保存动作。失败输入不丢失。
- 平台词“淘宝、京东、拼多多、网购”视为中性语境，不单独推断类别，也不否定明确商品用途；
  咖啡、耳机、礼物和冲突用途仍可保持未判断。固定合成场景及局限见第二阶段记录。

## 后续证据与耐用性修订（同日）

第二阶段平台词单纯中性化已撤回，随后以保留未知片段/强弱证据/物品边界的实现替代；
完整用途可以判断，平台、品牌或未解释商品不能独自判断，个人标签不自动生成。词表与词法结构已调整，
历史“本轮未调整词库”只描述第一阶段。分类参数、三类别、schema 与显式学习语义保持。

超过 60 条的月份/搜索采用明确范围与总数的分页，整月统计仍完整；新查询从第一页开始，
编辑完成后重新计数，动画补位不能丢弃另一条未完成输入。隐藏 Review 的数据读取推迟到进入前，
不让每次 Capture 保存重复分类整月；进入后仍立即显示最新完整统计，没有后台猜测或陈旧缓存。
实证与回退见 STARTUP_AND_JOURNEY、STUDENT_DURABILITY、STUDENT_PHASE4。

同日所有者另授权开源准备：采用 MIT，版权署名使用仓库所有者 Lorentz-Caldfilis；允许免费使用、修改和再分发，保留原版权及许可。计划审计可公开历史、依赖与二进制再分发资料，完善贡献和私密安全报告说明；完成后仍保持仓库私有，由所有者切换公开。此授权不转移他人贡献的版权。

本人已明确要求录入时选择用途、本地图片背景、二次元极简软件图标及 EXE 发行准备，并授权提交、推送和合并 GitHub 项目。本条款在其范围内优先于旧版 Capture 不放分类控件的限制。

- 时间下新增“用途”一行，直接显示生活、工具、娱乐三个可切换选项。选择可再次点击取消，未选择时仍在读取时自动判断；不增加必填步骤，不打断金额→Enter→说明→Enter。所选类别是明确个人标签，随记录写入并参与现有本机学习。提交成功后清除本笔选择；写入失败保留，草稿及新增撤销保留类别，开始下一笔后撤销上一笔不覆盖下一笔。
- 低频菜单可选择本地图片作为背景，并恢复默认背景。图片仅在本机导入到独立于账本的外观文件；两空间共享同一背景，裁剪填充，前景使用稳定的浅色阅读层，不牺牲对比度。无联网、无背景评分、不增加第三个空间。替换失败保留旧背景，损坏背景回退默认并保留账本。
- 图标为原创二次元极简形象，保证小尺寸轮廓清楚，生成 PNG 与 Windows 多尺寸 ICO，应用窗口、任务栏和 EXE 使用同一资源。
- 版本 1.2.0。以上为本轮实施与验收要求，完成状态只按实测写入 STATUS；先通过源码、冻结版、解压包及远端 CI 后合并，发行目录不覆盖同名旧包，公开准备中的旧远端 Release 转 draft 保留，不读取真实账本做测试。
