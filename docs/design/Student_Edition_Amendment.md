# PC Student edition 设计修订（2026-09-30）

本轮用户授权重新审视除本地优先和习惯学习之外的设计哲学。以下限定条款优先于旧规范；
其他条款继续适用。不是全面改写产品定位，也不改变许可证或发布状态。

| 原规则 | 新行为与原因 |
|---|---|
| 无文字圆点、隐藏式边缘切换 | 两个原生按钮“记一笔 / 看账单”，维持底部与固定左右关系；新用户无需猜测圆点用途，键盘能直接到达。边缘、Alt+方向键仍可用。 |
| 品牌在使用页面完全退场 | 左上角小号 Cashing 标识帮助识别窗口，金额仍是主视觉；不加品牌动画。 |
| Capture 只有输入内容 | 增加“记下这一笔”、回车路径和粘贴提示；首次使用不需要读说明书。无新增必填字段。 |
| 仅标准数字逐字段输入 | 空金额框 Ctrl+V 可粘贴人民币金额及说明（如 `18.5 午饭`）；完整校验，只填入待确认内容，不自动保存。多行、外币、非法精度和可能截断的说明整体拒绝。 |
| 撤销保存必定恢复原输入 | 如果下一笔已输入或时间已手动选择，保留下一笔；账本仍撤销上一笔。优先避免覆盖尚未保存的劳动。 |
| 编辑只能继续纠正 | 每次已提交字段修改提供短时撤销，恢复原始类别来源与学习标签；拒绝覆盖后续修改。原生 Ctrl+Z 继续属于文本；Ctrl+Alt+Z 撤销通知中的操作。 |
| 用户指定类别只能再指定 | “自动判断”移除当前记录的个人标签；其余历史纠正继续参与学习。明确选中相同类别也能确认个人选择，未交互不产生标签。 |
| 草稿关闭时保存 | 输入停止 350ms 后原子替换，提交/撤销后立即同步；退出时写失败保留窗口和输入。仍不保证跨账本与草稿文件的断电事务。 |
| Utility 只有目录和关于 | 添加本地账本备份，降低手动复制出错风险；没有第三个空间、登录、遥测或网络依赖。 |

类别仍是生活、工具、娱乐或暂未判断；金额仍存整数分。算法不读取真实个人数据作开发评估，
不把自动类别写回当训练样本。三个类别的算法参数与词库本轮未调整。

视觉继续沿用浅色、集中内容列、克制动效。次级阅读色加深，主按钮改为更清晰的蓝色。
说明输入固定可用宽度，避免提示和输入过早被省略；长通知限制宽度并换行。

回退：按开发记录反向 revert 各批提交；schema 保持 v3，不需要逆迁移。
