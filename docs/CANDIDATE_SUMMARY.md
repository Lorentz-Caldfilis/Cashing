# Cashing 学生版候选：这次能感受到什么

这仍是本地开发候选，没有正式发布，也没有账号或云服务。

- 记一笔更顺手：金额和说明可以一次粘贴；草稿自动保存；保存失败保留输入，成功后可撤销。
- 纠错更可靠：自动与自选来源可见，改说明不会冒充人工分类；恢复自动和撤销也恢复对应学习。
- 分类更谨慎也更有用：完整用途能越过购物平台名，未知物品和混合用途不会被弱子串吞掉。
  学习仍依赖自己的明确选择；没有联网模型。合成测试改善不代表已懂每个人的消费。
- 大账本可逐页查看：每页 60 条，显示完整结果数量，月份总额包含整月。
- 备份有验证路径：本地快照可复制到新的数据目录恢复；指南解释升级和旧版本回退边界。
- Windows 候选可自动构建并检查解压启动，包内依赖、授权来源和文件摘要可核对。

仍需所有者决定：是否公开、采用哪种源代码许可证、最终发行包的第三方再分发条件、
安全问题私密报告渠道、正式版本与签名策略。现有许可不变，本轮不发布 Release。
真实 Windows 输入法、触控板、跨屏 DPI、物理断网和无 Python 干净机器仍待人工验收。
大数据首屏明显改善，但本测试环境首次 Qt 启动约 3.3–3.6 秒，未达到预设 2 秒。

使用和恢复步骤见 [使用指南](USER_GUIDE.md)，验收证据见
[耐用性记录](development/STUDENT_DURABILITY.md) 和 [第四阶段分类记录](development/STUDENT_PHASE4.md)。
